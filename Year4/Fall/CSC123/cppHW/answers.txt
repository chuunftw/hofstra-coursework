Bubblesort.cpp

1. The swap in bubblesort() copied the students pointer (original lines 48-50).
   Temp freed the array,
   so printing A[k+1] caused a use after free b/c it still pointed to that array.

2. Changed students to unique ptrs, used make_unique to allocate the array and
   commented out roster destructor. Smart pointers free array automatically 

3. The initial swap doesn't compile b/c it tried to copy rosters, 
   rosters that own a unique ptr can't be copied b/c the pointer has a single owner. 

4. Replaced the three copy statements with swap(A[k], A[k+1]).
   This moved the rosters and transfers ownership of their arrays.

Matrixerror.cpp

1. clean() freed the matrix, then the destructor tried to free it again
   which is a double free. C=A*B leaked C's old array and copied the 
   temp pointer. The temp freed the array, so C.printm() tried to read freed memory.
   multiply() could read past a row b/c it kept going after a size mismatch.

2. Used double1d, double2d, and make_unique for the arrays. Passed them
   by reference when borrowing and moved them when replacing storage.
   Removed clean() and the destructor b/c smart pointers free the arrays.

Observers_problem.cpp

1. The original notify() loop (line 198) calls update(), which can call dump(),
   then detach(). investors.erase(investor_name) (line 193) removes the
   current entry. The loop then advances
   an invalid iterator, which can cause a segmentation fault.

2. Used an explicit iterator in notify(). Locked the weak_ptr, advanced
   the iterator, then called update() if the lock worked. If the investor
   removes itself, the loop is already at the next entry.

3. Ex of the same error:
   unordered_map<int, int> entries{{1, 10}, {2, 20}};
   auto it = entries.begin();
   entries.erase(it);
   ++it;  // Advances an invalid iterator
