PART 1 - BUBBLESORT AND ROSTERS
What the program does:
- A template function sorts an array using the < operator.
- It first sorts integers.
- It then sorts two roster objects by student count.
- Each original roster holds a raw pointer to a heap array of strings.
- Its destructor deletes that array.

Required work:
[ ] Identify exactly what causes the original crash.
[ ] Explain the memory-error type and the specific statements involved.
[ ] Trace ownership and pointer values during the swap.
[ ] Change string* students; to unique_ptr<string[]> students;
[ ] Change students = new string[count]; to
    students = make_unique<string[]>(count);
[ ] Remove the roster destructor.
[ ] Explain whether these prescribed changes alone fix the entire program.
[ ] Explain any new compilation problems.
[ ] Modify bubblesort to handle rosters and ordinary sortable values.
[ ] Confirm the corrected program produces the expected output.

Restrictions:
- Do not modify main, except temporary tracing output.
- Modify roster only as instructed.
- Do not replace the assignment with a different sorting design.

Original swap to investigate:
    T temp = A[k];
    A[k] = A[k+1];
    A[k+1] = temp;

Relevant original roster members:

    string* students;

Allocation:

Destructor:
