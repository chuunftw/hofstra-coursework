[ ] Uncomment operator_testing() in main after fixing the program.
[ ] Compile and exercise both the operator tests and normal program path.

Required ownership types:
    #include <memory>
    typedef std::unique_ptr<double[]> double1d;
    typedef std::unique_ptr<double1d[]> double2d;

Professor-provided allocation example:
    double2d matrix::alloc(int rows, int cols) {
        x = rows;
        y = cols;
        double2d new_matrix = make_unique<double1d[]>(x);
        for (int i = 0; i < x; i++) {
            new_matrix[i] = make_unique<double[]>(y);
        }
        return new_matrix;
    }

Important parameter warning from the assignment:
A function that only accesses an existing unique_ptr-owned array should
not take ownership accidentally. The given example is:
    void populate(double2d& m);
rather than passing double2d by value.
Passing an owning pointer by value would require an ownership transfer,
and the local owner would clean up its allocation when destroyed.

Suggested inspection order:
1. matrix members, constructors, alloc(), destructor, and clean().
2. trans() and multiply(), which replace allocations.
3. Arithmetic operators and operator_testing().
4. Velocity allocation and the functions using it.
5. main's allocations and manual cleanup.

Concepts to learn:
- Nested smart pointers for two-dimensional arrays.
- Borrowing through references versus transferring ownership.
- Rule of Zero and automatic cleanup.
- Returning objects and assigning results safely.
- Matching allocation lifetimes to owners.
