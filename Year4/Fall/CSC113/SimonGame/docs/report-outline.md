# Lab report working outline

Use the professor's Word template for the final report. It was not found at the
previously supplied path during inspection. This outline does not replace it.
Write the final explanation in your own words and use your actual results.

1. **Objective:** Describe the memory game and assignment requirements.
2. **Components:** List the actual board, LEDs, resistors, switches, sound part,
   breadboard, and wires. Include the sound part's identification.
3. **Design:** Include the Tinkercad/Fritzing schematic, wiring photo, pin table,
   and an explanation of pull-ups and LED current-limiting resistors.
4. **Algorithm:** Explain waiting, playback, and player input; sequence growth
   from one to four; comparison; success/failure; restart; and debounce.
5. **Implementation:** Explain your own code, helper functions, fixed sequence
   array, and release handling. Identify any reference material/AI help according
   to the course rules; the provided reference is AI-generated.
6. **Testing:** Fill in the hardware checklist with actual observations. Keep
   compilation/software checks separate from hardware/simulator results.
7. **Problems and changes:** Record bugs or wiring errors encountered and how
   you diagnosed and corrected them.
8. **Conclusion:** State which requirements were demonstrated and any limitations.
9. **References:** Cite Arduino documentation and other sources you used.
